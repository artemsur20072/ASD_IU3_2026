# №42. Вставка элемента в отсортированный массив

Бинарный поиск находит первую позицию с элементом `>= x` либо `n`, если её нет.
При сравнении с серединой отбрасывается половина интервала: если значение меньше `x`,
позиция правее середины, иначе середина остаётся возможной правой границей.
После завершения слева от позиции все элементы `< x`, справа — `>= x`.

В новом массиве копируется префикс, затем записывается `x`, затем копируется суффикс.
Так сохраняются неубывание и все исходные элементы. Вход не изменяется.

Поиск: `Tsearch(n) = Tsearch(n / 2) + Θ(1) = O(log(n + 1))`.
Копирование суммарно `n` элементов и выделение результата: Θ(n).
Итого Θ(n) времени, Θ(1) рабочей памяти и Θ(n) памяти нового результата.
Логарифмическая сложность относится только к поиску позиции, не ко всей вставке.


## Ввод и вывод

Ввод: `n`, n элементов массива, вставляемое число `x`. Пробелы и переводы строк равнозначны.
Элементы и параметры — `int`, размеры — по условию `1 < n < 10^5`.
Входные массивы должны быть отсортированы по неубыванию.
Вывод: ответ одной строкой без подсказок.

## Время и память программы

`n`, `m` — длины массивов. Рабочая память не включает вход и результат.
Итоговое время учитывает ввод и вывод, общая память — все хранимые массивы.

| № | Задача | Время | Рабочая память | Память результата | Общая память |
|---|---|---|---|---|---|
