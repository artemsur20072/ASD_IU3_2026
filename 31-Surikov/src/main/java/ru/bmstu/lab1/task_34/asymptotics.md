# №34. Максимальная сумма непрерывного подмассива

`endingHere` — максимальная сумма непустого подмассива, заканчивающегося в текущей
позиции. Такой подмассив либо начинается здесь, либо продолжает оптимальный подмассив
предыдущей позиции: `endingHere = max(a[i], endingHere + a[i])`.
`maximum` хранит максимум по всем уже рассмотренным окончаниям.

Начальные значения берутся из первого элемента, а не из нуля. Поэтому для массива
из отрицательных чисел ответом становится наибольший элемент, а не сумма пустого массива.

Одна обработка каждого элемента: `T(n) = Θ(n)`, рабочая память Θ(1).
Входной массив требует Θ(n). Суммы имеют тип `long`:
при `n < 10^5` и элементах `int` абсолютная величина любой суммы меньше `2.15 · 10^14`.


## Ввод и вывод

Ввод: `n`, n элементов массива. Пробелы и переводы строк равнозначны.
Элементы и параметры — `int`, размеры — по условию `1 < n < 10^5`.
Массив должен быть непустым.
Вывод: ответ одной строкой без подсказок.

## Время и память программы

`n`, `m` — длины массивов. Рабочая память не включает вход и результат.
Итоговое время учитывает ввод и вывод, общая память — все хранимые массивы.

| № | Задача | Время | Рабочая память | Память результата | Общая память |
|---|---|---|---|---|---|
| 34 | Максимальная сумма подмассива | Θ(n) | Θ(1) | Θ(1) | Θ(n) |
