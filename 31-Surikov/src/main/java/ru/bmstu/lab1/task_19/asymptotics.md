# №19. Объединение отсортированных массивов

Два указателя обозначают первые ещё не взятые элементы массивов. Меньший из них
переносится в результат. При равенстве берётся элемент первого массива; повторы
сохраняются. После исчерпания одного массива копируется оставшаяся часть второго.

Перед каждой итерацией результат содержит наименьшие из уже доступных элементов
в неубывающем порядке. Следующий выбранный минимум продолжает этот порядок.
Остаток второго массива уже отсортирован и не меньше последнего добавленного элемента.

Каждый элемент записывается ровно один раз: `T(n, m) = Θ(n + m)`.
Указатели занимают Θ(1), новый массив — Θ(n + m). Входы не изменяются.


## Ввод и вывод

Ввод: `n`, n элементов первого массива, `m`, m элементов второго массива. Пробелы и переводы строк равнозначны.
Элементы и параметры — `int`, размеры — по условию `1 < n < 10^5`.
Входные массивы должны быть отсортированы по неубыванию.
Вывод: ответ одной строкой без подсказок.

## Время и память программы

`n`, `m` — длины массивов. Рабочая память не включает вход и результат.
Итоговое время учитывает ввод и вывод, общая память — все хранимые массивы.

| № | Задача | Время | Рабочая память | Память результата | Общая память |
|---|---|---|---|---|---|
| 19 | Слияние | Θ(n + m) | Θ(1) | Θ(n + m) | Θ(n + m) |
