# №38. Циклический сдвиг влево

Расстояние нормализуется: `d = floorMod(k, n)`. Разделим массив на `A` длины `d`
и оставшийся блок `B`. Разворачиваем `A`, затем `B`, затем весь массив:
`AB → reverse(A) reverse(B) → BA`. Внутренний порядок обоих блоков восстанавливается.
Отрицательные значения `k` дополнительно поддержаны как сдвиг вправо.

Разворот отрезка длины `s` требует `floor(s / 2)` обменов. Всего:
`floor(d / 2) + floor((n - d) / 2) + floor(n / 2) ≤ n` обменов.
В худшем случае время Θ(n), рабочая память Θ(1); развороты итеративные.
При нулевом нормализованном сдвиге сам метод работает за Θ(1), но программа
всё равно читает и выводит `n` элементов за Θ(n). Пустой массив обрабатывается до деления.


## Ввод и вывод

Ввод: `n`, n элементов массива, сдвиг `k`. Пробелы и переводы строк равнозначны.
Элементы и параметры — `int`, размеры — по условию `1 < n < 10^5`.
Вывод: ответ одной строкой без подсказок.

## Время и память программы

`n`, `m` — длины массивов. Рабочая память не включает вход и результат.
Итоговое время учитывает ввод и вывод, общая память — все хранимые массивы.

| № | Задача | Время | Рабочая память | Память результата | Общая память |
|---|---|---|---|---|---|
| 38 | Сдвиг влево | Θ(n) | Θ(1) | На месте | Θ(n) |
