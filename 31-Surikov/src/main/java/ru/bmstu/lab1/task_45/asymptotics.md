# №45. Разбиение по опорному элементу

Используются три границы: `lessEnd`, `current`, `greaterStart`. Поддерживаются зоны:

- `[0, lessEnd)` — элементы `< p`;
- `[lessEnd, current)` — элементы `= p`;
- `[current, greaterStart)` — ещё не просмотренные элементы;
- `[greaterStart, n)` — элементы `> p`.

Малый элемент меняется местами с первым элементом средней зоны, затем первые две
границы сдвигаются. Равный элемент расширяет среднюю зону. Большой элемент меняется
местами с последним непроверенным; правая граница уменьшается, а полученный элемент
остаётся для проверки. Обмены сохраняют набор и количество исходных элементов.

В каждой итерации длина непроверенной зоны уменьшается ровно на один, поэтому
выполняется ровно `n` итераций: `T(n) = Θ(n)`. Когда зона пуста, всё разбиение корректно.
Три индекса и временная переменная обмена требуют Θ(1) рабочей памяти.
Порядок внутри групп не сохраняется, что допускается условием.


## Ввод и вывод

Ввод: `n`, n элементов массива, опорное значение `p`. Пробелы и переводы строк равнозначны.
Элементы и параметры — `int`, размеры — по условию `1 < n < 10^5`.
Вывод: ответ одной строкой без подсказок.

## Время и память программы

`n`, `m` — длины массивов. Рабочая память не включает вход и результат.
Итоговое время учитывает ввод и вывод, общая память — все хранимые массивы.

| № | Задача | Время | Рабочая память | Память результата | Общая память |
|---|---|---|---|---|---|
| 45 | Разбиение по опорному элементу | Θ(n) | Θ(1) | На месте | Θ(n) |
